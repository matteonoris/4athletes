TestFlight build focused on Health sleep scoring, trend charts, and strength PR accuracy.

- Assigns overnight sleep stages to the wake-up date so pre-midnight sleep is included.
- Updates sleep regularity to consider both bedtime and wake time across the recent window.
- Refreshes today's Health cache behavior so partial morning sleep data can be corrected.
- Shows score trend bands as rolling variability instead of a single static deviation.
- Uses the latest strength PR log as the current one-rep max across training screens.
